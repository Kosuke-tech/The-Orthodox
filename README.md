# Shopify-demo_The-Orthodox

アパレル系ECサイトを想定して制作した、Shopifyデモストア用のテーマ開発リポジトリです。  
Dawnをベースに、セクション追加・商品ページ改修・UI調整を行っています。

## 概要
アパレル商材の販売を想定し、ブランドイメージを損なわないデザイン表現と、商品ページ・一覧ページの見やすさを意識して制作したデモテーマです。  
見た目だけでなく、既存テーマをベースにした改修や追加実装を想定した構成にしています。

## 主な実装内容
- ヒーローや各種セクションのカスタマイズ
- 商品ページのカスタマイズ
- UI / レイアウト調整
- block / setting を用いた管理画面対応
- CSS / JavaScript を用いた見た目・挙動の調整

## 使用言語
- Shopify Liquid
- HTML
- CSS
- JavaScript

## 補足
デモ用リポジトリのため、一部画像・文言は検証用です。
